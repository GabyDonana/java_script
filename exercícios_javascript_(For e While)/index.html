Sobre os Sistemas:

Neste espaço, você vai explorar cinco mini sistemas interativos desenvolvidos em HTML, CSS e JavaScript que trazem as estruturas de repetição For e while para cenários reais do dia a dia, como controle de estoque, relatórios de notas e validação de senhas. O projeto demonstra de forma prática como o For é a escolha ideal para percorrer listas de dados de maneira precisa, enquanto o While se destaca ao repetir ações até que uma condição específica seja atendida. Muito além de apenas contar números ou executar loops automáticos, cada página funciona como um desafio único, provando que programar é usar a lógica e a criatividade para resolver problemas reais do cotidiano.

Sistemas Criados:

• Sistema de estoque

• Sistema de caixa

• Sistema de senha secreta

• Relatório de notas

• Conferência de valores
